This repository reproduces **all figures of the article and its supplement**,
the **syllable synthesis pipeline**, and the **MP4 stimulus videos**, from the
original EMA corpus (Kasper et al.) to the final outputs.

## 1. What this repository does

The pipeline takes articulatory trajectories (EMA + Maeda model parameters),
aligns them across conditions with **Canonical Time Warping (CTW)**, computes
correlations and statistics between conditions A and B, and produces:

- Figures 2a, 2b, 3 of the article and Figures S1–S5 of the supplement;
- a corpus of synthesized short syllables (`synthesis/`);
- the stimulus videos `CondA.mp4`, `CondB.mp4`, `mixAB.mp4` (`video/`).

The mapping between the original research scripts and this refactored
repository is documented in `docs/mapping.md`.

## 4. Quick start — reproduce everything in one command

```bash
python run_all.py --stage all
```

This runs the full chain, in order (each stage can also be run on its own):

| Stage | Regenerates | Approx. duration |
|---|---|---|
| `data` | `copyparam`, `copywav`, `copyformants` from the raw EMA corpus | ~45 min |
| `ctw` | `paramodelctw(random)`, `modelctw(random)` (CTW conditions A/B) | ~75 min |
| `figures` | the 9 article/supplement PNGs + the Figure 2a/2b statistics | ~1 min |
| `synthesis` | demonstration syllable corpus | ~15 s |
| `videos` | the MP4 stimulus chain (requires ffmpeg) | ~1 min |

(The full `--stage all` run takes about 2 hours on one core; the
dominant cost is the VLAM formant synthesis, ~35 s per stimulus.)

Every generator writes under `results/regenerated/` (same tree structure
as `data/`); the archived `data/` directory is never modified, and the
comparison against the archived values is automated by the test suite:

```bash
python -m pytest tests/ -q        # ~20 min; see tests/test_reproducibility.py
```

The dependency graph of the pipeline (which script produces which data
set, and the numerical-equality guarantees) is documented in
`docs/PIPELINE.md`. Each figure script remains self-contained and can
still be run directly, e.g.:

```bash
python figures/fig2a_articulatory_correlations.py   # -> results/figures/
```

## 5. Reproducing the pipeline stage by stage

```bash
# 1. Reference tracks: raw EMA (.mat) -> 6 articulatory parameters,
#    then VLAM synthesis -> audio + formant tracks
python src/batch_parameters.py --out-root results/regenerated/data
python src/make_reference_tracks.py

# 2. CTW conditions A and B (aligned parameters + formant conversion)
python src/ctw_condition_a.py
python src/ctw_condition_b.py

# 3. All article + supplement figures (8 scripts, 9 PNGs)
python figures/fig2a_articulatory_correlations.py
python figures/figs1b_ctw_paths_condition_b.py
# ... see docs/mapping.md for the complete list

# 4. Short-syllable synthesis (Tau-model articulatory synthesizer)
python synthesis/run_synthesis.py --text "ba.du abi" --no-video

# 5. Stimulus videos (requires ffmpeg on PATH, or 'pip install imageio-ffmpeg')
python run_all.py --stage videos
```

Detailed, beginner-oriented tutorials are in `docs/` and the compiled
`docs/documentation.pdf`; the usage manual of the refactored functions
(CLI commands, importable API of every module, reproducibility
guarantees) is the compiled `docs/usage_manual.pdf` (source:
`docs/usage_manual.tex`).
